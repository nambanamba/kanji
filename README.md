# 📘 国語 漢字と言葉 ドリル

四谷大塚「予習シリーズ」5年下の**国語「漢字と言葉」**（漢字の読み書き＋和語・慣用句・四字熟語・類義語対義語など）に特化した学習アプリです。`kosukequiz-battle`（社会・理科の対戦暗記アプリ）とは独立した姉妹アプリで、**対戦機能は持ちません**。

---

## 🌟 構成

このアプリは2つの独立したパートを持ちます（画面上部のタブで切り替え）。

1. **📝 漢字パート**（`kanji-print-app`と同じ方式）
   - 単元・問題数を選んで印刷（テスト欄＋なぞり書き練習マス目のA4プリント）
   - 紙で解いた後、画面で「〇 できた／✕ できなかった」を記録
   - 間隔反復で、苦手な漢字が次回優先的に出題される
2. **🈁 言葉パート**（画面完結の一問一答クイズ、対戦なし）
   - 単元・ジャンル（和語／慣用句／四字熟語など）・問題数を選んでクイズ開始
   - 1問ずつ表示 →「答えを見る」→ 自己採点（〇 正解できた／✕ まちがえた）
   - 間隔反復で、苦手な問題が次回優先的に出題される

漢字と言葉は完全に別データ・別localStorage（進捗記録）で管理され、互いに影響しません。

---

## 🚀 使い方

1. `index.html` をブラウザで開きます（外部サーバー不要、スタンドアロン動作）。
2. 画面上部の「📝 漢字」「🈁 言葉」タブで科目を切り替えます。
3. 各科目内で単元・問題数（漢字は印刷、言葉はジャンルも）を選んで開始します。

---

## 📁 ファイル構成

- `index.html` - アプリ本体（漢字パート・言葉パートのUI・ロジック・印刷スタイル）
- `data.js` - `KANJI_DATA`（漢字書き取り）・`KOTOBA_DATA`（言葉クイズ）・単元一覧
- `images/` - 言葉クイズで図版が必要になった場合の置き場（現状未使用）
- `ROLE.md` - このフォルダのセッションの役割・経緯
- `README.md` - 本ドキュメント
